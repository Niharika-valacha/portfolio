# Design Brief: Release 1 (for the design chat)

**Product:** Portfolio of Niharika Valacha, AI / Applied AI Engineer (Backend & AI Systems). Full spec: `PRODUCT.md`.

## Feedback so far
- Drafts so far looked **childish / amateur**: too cartoony, tilted stickers, doodles, a big mascot in the hero.
- Wanted: **clean, mature, premium.** Creative, but in a restrained, well-crafted way.
- Palette decided: **Midnight & Cream** (see `PRODUCT.md` §4, preview `design/palette/palette.html`). Replaces the old peach/plum palette.
- Mimi decided: **enamel-pin style**, midnight body, muted gold lines, ember forehead star, 2 eyes (4 when thinking, later). Replaces the cream cartoon Mimi.

## Release 1 pages (frozen)
1. **Home**: hero, projects, experience, skills, contact
2. **Recruiter Mode**: whole resume on one calm screen
3. **2 case studies**: agent latency fix (3.8s → 1.04s), Agent Studio
4. **404**
5. **Mimi** (cat mascot): small, in the corner only, no chat in Release 1

## Must-haves
- Recruiter finds resume + contact in under 5 seconds
- Separate mobile and laptop layouts
- Light theme + dark theme
